## 4. 明确不可模拟的部分

| 项 | 为什么不能 |
|---|---|
| futex PI UAF 内核利用 | 需要真 5.4.295-qgki 内核与该漏洞的内存布局 |
| W1 关 SELinux / W2 写 `cred` | 内核态写操作，x86 云电脑无对应内核 |
| `memstart probe` / KASLR slide | 依赖真机物理内存映射与 `/proc/iomem` |
| W2 的 `fork()` 400 子进程风暴 | 与真机调度/内存压力相关，模拟无意义 |
| KernelSU late-load / `insmod` | 需要 vermagic 匹配的真内核与 ko |
| Android Runtime / `system_server` | 无 Android 系统镜像与模拟器 |
| App 真实安装与 UI 交互 | 无 Android 设备或 emulator |
